# Coordination Compounds Visual Learning

A static site teaching Coordination Compounds visually, built entirely by agents.

## Stack & Decisions
- **Framework**: Astro 5 (minimal template)
- **Math**: KaTeX via CDN
- **Styling**: Vanilla CSS, black background, minimal UI, thin borders as requested.
- **Data**: JSON extracted from the nomad repo and restructured.
- **Visuals**: SVG and DOM based interactive components (vanilla JS).

## Concepts Covered
- Werner's theory
- Ligands and Chelates
- Coordination Number and Geometry
- IUPAC Nomenclature
- Isomerism (Structural and Stereo)
- Valence Bond Theory
- Crystal Field Theory
- Stability of Complexes
- EAN Rule
- Metal Carbonyls
- Applications

## Deployment
Automated to GitHub Pages via `.github/workflows/deploy.yml`.
